Features

Everything you need to go from offer to contract.

Offer extraction

Paste an offer and the AI extracts title, company, location, salary, requirements and responsibilities.

Tailored CV

Adapt your CV to each offer, in the language you choose. Export to PDF in one click.

Cover letter

Generate personalized letters ready to send, with subject, greeting and sign-off.

Technical test

Interactive tests with automatic grading and multiple question types.

ATS analysis

Measure your fit against the offer and spot the keywords missing from your CV.

Kanban pipeline

Track every offer from «Saved» to «Offer» with a drag-and-drop board.

How it works

From a pasted offer to a contract, in three steps.

1. Install & configure

Clone the repo, run bun run tauri dev and add your API key.

2. Paste the offer

The AI structures it automatically: title, company, requirements and more.

3. Generate & apply

Create CVs, letters, tests and ATS analysis in one click, and track your progress.

Installation

You need Bun and Rust (for Tauri). Then, four commands.

# 1. Clone the repository
git clone https://github.com/luisfer-cli/librejob.git
# 2. Enter the project
cd librejob
# 3. Install dependencies
bun install
# 4. Launch the app
bun run tauri dev

On first launch, open Settings to configure your AI provider and API key.

Frequently asked questions

Is it free?

Yes. LibreJob is free and open-source software. You can use it, modify it and contribute freely.

Where is my data stored?

Everything is stored locally, in a SQLite database on your machine. Your API key and your offers never leave your machine (except for the calls you make to your AI provider).

Do I need an API key?

Yes, for the AI features (CVs, letters, tests and ATS analysis). You can use any provider compatible with the OpenAI API.

Which systems does it run on?

Built with Tauri 2, it runs on Linux, Windows and macOS.
