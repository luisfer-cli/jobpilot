Características

Todo lo que necesitas para pasar de la oferta al contrato.

Extracción de ofertas

Pega una oferta y la IA extrae título, empresa, ubicación, salario, requisitos y responsabilidades.

CV especializado

Adapta tu currículum a cada oferta, en el idioma que elijas. Exporta a PDF en un clic.

Carta de presentación

Genera cartas personalizadas listas para enviar, con asunto, saludo y despedida.

Prueba técnica

Pruebas interactivas con corrección automática y varios tipos de pregunta.

Análisis ATS

Mide tu encaje con la oferta y detecta las keywords que faltan en tu CV.

Pipeline kanban

Sigue cada oferta de «Guardada» a «Oferta» con un tablero de arrastrar y soltar.

Cómo funciona

De la oferta pegada al contrato, en tres pasos.

1. Instala y configura

Clona el repositorio, ejecuta bun run tauri dev y añade tu API key.

2. Pega la oferta

La IA la estructura automáticamente: título, empresa, requisitos y más.

3. Genera y postula

Crea CVs, cartas, pruebas y análisis ATS a un clic, y sigue tu progreso.

Instalación

Necesitas Bun y Rust (para Tauri). Luego, cuatro comandos.

# 1. Clona el repositorio
git clone https://github.com/luisfer-cli/librejob.git
# 2. Entra en el proyecto
cd librejob
# 3. Instala las dependencias
bun install
# 4. Lanza la aplicación
bun run tauri dev

Al primer arranque, abre Ajustes para configurar tu proveedor de IA y tu API key.

Tecnología

Un stack moderno, ligero y 100 % local.

Angular 20 + TypeScript

Interfaz con componentes standalone y strict templates.

Tauri 2 + Rust

Escritorio nativo y ligero. La IA se llama desde el backend Rust.

SQLite

IA compatible con OpenAI

OpenRouter, OpenAI, Groq, Together, Mistral, DeepSeek, Perplexity…

Preguntas frecuentes

¿Es gratuito?

Sí. LibreJob es software libre y de código abierto. Puedes usarlo, modificarlo y contribuir libremente.

¿Dónde se guardan mis datos?

Todo se guarda en local, en una base de datos SQLite de tu equipo. Tu API key y tus ofertas no salen de tu máquina (salvo las llamadas que haces a tu proveedor de IA).

¿Necesito una API key?

Sí, para las funciones de IA (CVs, cartas, pruebas y análisis ATS). Puedes usar cualquier proveedor compatible con la API de OpenAI.

¿En qué sistemas funciona?

Al estar construido con Tauri 2, funciona en Linux, Windows y macOS.
